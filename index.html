Architecture Reference · 2026-11-19

PDF Preview & Search Techniques

  • Inline Browser Rendering: Native HTML <iframe> and <object> tags render PDF files directly, while Mozilla's PDF.js provides full client-side canvas control.
  • Local File Object URLs: Drag-and-drop and file inputs call URL.createObjectURL(file) for instant zero-upload previews.
  • Remote Link Fallbacks: External URL inputs support direct PDF embedding as well as viewer-wrapper fallback formatting when servers restrict framing.
  • Real-Time Client Filtering: Maintaining a master document array enables instant keyword, author, and category filtering on every keystroke.
